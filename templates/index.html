Acerca del modelo

Cómo funciona ValoraTerreno.

1. Datos

Se cargan 750 terrenos sintéticos desde un CSV local con Pandas. No se usa base de datos externa.

2. Entrenamiento

Un Pipeline de scikit-learn aplica OneHotEncoder a las variables categóricas y entrena un RandomForestRegressor con el 80 % de los datos.

3. Evaluación

Con el 20 % restante se calculan el MAE y el R², que se muestran en el panel principal.

4. Predicción

El formulario envía los datos con fetch() a /api/predict, que aplica el mismo procesamiento y devuelve el precio en JSON.
